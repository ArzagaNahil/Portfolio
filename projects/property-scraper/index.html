Cómo funciona en 6 pasos

1

Instala

Descarga la extensión desde Chrome Web Store o Edge Add-ons con un clic

2

Abre un portal

Navega a Idealista, Fotocasa, Habitaclia, YaEncontré o Pisos.com

3

Clic en el icono

Abre la extensión desde la barra de herramientas de tu navegador

4

Extrae

Pulsa "Extraer propiedades" y la extensión lee automáticamente todos los anuncios

5

Filtra y exporta

Refina por precio, m² o habitaciones, luego exporta a CSV o JSON

6

Guarda

Los datos se guardan automáticamente en tu navegador para consultarlos después

Tu privacidad es primero

✓
Sin recopilación de datos

La extensión no recopila, almacena ni transmite ningún dato personal, información de navegación o datos identificables del usuario.

✓
Sin servidores externos

Toda la operación se realiza localmente en tu navegador. No existen conexiones a servidores externos, APIs o servicios de análisis.

✓
Almacenamiento 100% local

Los datos extraídos se almacenan únicamente en el almacenamiento local del navegador y no son accesibles por ninguna otra extensión o servicio.

✓
Permisos mínimos

Solo solicita activeTab (leer la página activa) y storage (guardar propiedades). No necesita permisos adicionales para funcionar.

✓
Acceso limitado a portales

La extensión solo se activa en Idealista, Fotocasa, Habitaclia, YaEncontré y Pisos.com. No tiene acceso a ningún otro sitio web.

✓
Código abierto y transparente

El código fuente está disponible para revisión. Puedes verificar exactamente qué hace la extensión antes de instalarla.
